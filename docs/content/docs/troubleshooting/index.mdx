Failure modes that recur when operating SWE-Lego-RL, distilled to **symptom → root cause
→ fix**. The pages here cover the ones you are most likely to hit; the
[full index](#full-write-up-index) at the bottom lists every incident write-up in the
repo, including the ones too situational to promote to a page.

<Callout title="Most config-level problems never get this far" type="info">
`PREFLIGHT_ONLY=1` catches the mistakes that would otherwise cost a multi-hour run —
parser mismatch, topology that doesn't add up, R3 without the new verl tree, no
reachable image source. Run it first; see [Preflight](/docs/run-training/preflight).
</Callout>
