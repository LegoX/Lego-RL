This documentation is a [fumadocs](https://fumadocs.dev/) (Next.js) static
export, deployed to a dedicated Cloudflare Pages project (`swe-lego-rl`).

```bash
cd docs
export NVM_DIR="$HOME/.nvm"; [ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"; nvm use 22
npm install            # first time
npm run dev            # local preview at http://localhost:3000
npm run build          # static export to out/
bash deploy_cloudflare_pages.sh   # build + deploy to swe-lego-rl
```

The deploy script asserts Node >= 20 (via nvm), reuses the Cloudflare credentials
(`CLOUDFLARE_API_TOKEN` + `CLOUDFLARE_ACCOUNT_ID` from `.env.cf` or
`~/.config/rl_dashboard_cloudflare.env`), and publishes `out/`. Override the
project with `PROJECT_NAME=...` (or `DOCS_PROJECT_NAME=...` in the env file).

<Callout title="Edits are not live until you deploy" type="warn">
The site is a static export: changing an `.mdx` file or an asset under
`public/` has no effect on the published site until `npm run build` +
`deploy_cloudflare_pages.sh` run again. A broken image or stale page on the
live site usually means the source was fixed but never redeployed.
</Callout>

## Adding a page

1. Drop an `.mdx` file under `content/docs/` with `title` + `description`
   frontmatter.
2. Add its slug to the folder's `meta.json` `pages` array.

## Conventions

- **Terminology follows the technical report**: *run validation* (the
  configuration → constraint checking → resource inspection → confirmation
  sequence), *agent plugin*, *trial* (execution-side) vs *rollout*
  (training-side), *routing replay (R3)*. The page and command names `Preflight`
  / `PREFLIGHT_ONLY` are kept because they name the actual script surface.
- **American English** spelling (behavior, not behaviour).
- Cite sources for concepts that originate in the literature — see
  [Core Concepts](/docs/core-concepts#references) for the reference list.

## llms.txt

`npm run build` regenerates `public/llms.txt` (a machine-readable index of every
page with its description) via `scripts/gen-llms.mjs`, so AI tools can discover
and cite the documentation. It is served at
[`/llms.txt`](https://swe-lego-rl.pages.dev/llms.txt).
